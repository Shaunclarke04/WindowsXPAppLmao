(the updated code is in the repo). But that said, since i had Visual Studio 2008 installed, i installed Visual C# as well to screw around with since its what im most comfortable with and wanted to see how different it was to modern C#. As it turns out, not that different. SO i was screwing around and decided to make this app that runs natively on XP (and presumably other versions too) using .NET 3.5
